<Info>
  Each Space has its own Knowledge Base that is available to all members of that Space.
</Info>

The shared Knowledge Base helps a team work from the same trusted project context while keeping each member's chats and workflows private.

## Using shared project knowledge

All Space members can use shared project knowledge in their own chats and workflows. This helps teams apply the same requirements, standards and reference material across their work in disQo.ai.

Useful shared content can include:

- Requirements and specifications
- Testing standards and guidance
- Project documentation
- API specifications
- Reference files
- Reusable AI-generated outputs

## Saving useful outputs

Useful chat attachments and AI-generated outputs can be saved to the Space Knowledge Base so other Space members can reuse them.

Files and folders added to the Space Knowledge Base can then be used by other members in their own chats and workflows.

## Privacy

Sharing a Knowledge Base does not make users' chats or workflows visible to other Space members.

Each member continues working in their own private chats and workflows while using the same shared project knowledge as context.
