## 1.7.0 - Direct File Upload to Chat (03/08/2026)

### Added

- **Direct File Upload** to Agent chats — upload files directly to new conversations without first adding them to the Knowledge Base, with drag-and-drop support.

## 1.6.0 - API Documentation Analyser and API Test Generator Agents Added (16/07/2026)

### Added

- **API Documentation Analyser** and **API Test Generator** are now live in production, powered by real Foundry backends. Upload an OpenAPI specification to receive a structured analysis report covering spec quality, documentation coverage, test generation readiness, and recommended improvements — or generate Playwright API test cases with full endpoint-level coverage, test case breakdowns, and downloadable test scripts.
- Analytics for API Documentation Analyser and API Test Generator are now available in the Analytics section, showing time and total cost savings.

## 1.5.0 - Save Agent Output to KB and Advanced Filtering (22/06/2026)

### Added

- Save agent output to the Knowledge Base to inform further chats, supporting CSV and Markdown formats.
- Advanced filtering for Azure DevOps and Jira issues synced to the Knowledge Base by Status, Assignee, Sprint, and Type (Story, Task, etc).
- Advanced filtering capabilities available in Chats and Workflows.

## 1.4.0 - Seamless Integration and Image Workflows (29/05/2026)

### Added

- Direct write-back to Azure DevOps and Jira from disQo.ai.
- Write-back support for uploading generated user stories or test cases into your Azure DevOps or Jira project.
- Write-back actions to rewrite an existing user story and add comments to an existing story.
- Image recognition in chats and workflows to generate user stories or test cases from screenshots.

### Improved

- A more seamless path from content generation in disQo.ai to updating delivery tools (Azure DevOps and Jira).
- Better workflow coverage for image-led requirements and testing inputs.

## 1.3.0 - Image Chat Support (01/05/2026)

### Added

- Image support in existing agents: images can now be uploaded to the knowledge base and sent to agents, with responses based on the images provided.
- Automatic detection of deployments: if disQo.ai is open in a tab and a deployment happens in the background, users are now prompted to refresh before continuing.
- Specialised TDD agents for the development team to add or improve codebases by writing unit tests.

## 1.2.0 - Chat Memory (17/04/2026)

### Added

- Chat memory support to help agents retain useful context across conversations.

### Improved

- Better continuity in long-running chat sessions.
- Smoother handover between related tasks inside the same workflow.

### Fixed

- Resolved several issues where context was not consistently available between turns.
