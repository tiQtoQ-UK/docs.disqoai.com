  Organise your files into folders for easier management. Use clear, descriptive names for files and folders to improve search and automation accuracy.
</Tip>

## Using Files in Chats

You do not need to upload every file to the Knowledge Base before using it with an agent. You have two options:

- **Upload a file directly from your computer** — use files temporarily in a single Chat without storing them permanently.
- **Select an existing file from the Knowledge Base** — use files you have already uploaded and organised.

**When to use each approach:**

- Use direct uploads for temporary or Chat-specific context that you do not need to reuse across multiple Chats or Workflows.
- Use the Knowledge Base for files that you want to organise, store, and reuse across multiple Chats and Workflows.

For detailed instructions on uploading files directly to a Chat, see [Adding Files to a Chat](/agents/chats#adding-files-to-a-chat).

## Troubleshooting & Best Practices

<Warning>
  If you see a message that your integration is not connected, ensure you have authorised access to your Confluence or Jira account and try again.
</Warning>

- Only upload files you have permission to share.
- Keep your knowledge base up to date by regularly syncing with your integrations.
- Use filters to quickly find relevant documents.
